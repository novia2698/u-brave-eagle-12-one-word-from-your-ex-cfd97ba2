One word from your ex. The whole entry is a single word — the word an ex would use to describe you — and this one is **forgettable**.

An ex's cruellest verdict isn't hatred, it's erasure: not worth remembering. It lands instantly, it stings because it's true, and it's funny because there's no comeback to being forgotten.

## Run it

```sh
node main.ts
```

Writes exactly one word, `forgettable`, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).

## The entry

`main.ts` is a small Node 22 program: it takes the output directory from `MAKEFUN_OUTPUT_DIR` (falling back to `/output`), creates it, and writes the single word to `entry.txt` with no trailing newline and no extra whitespace — exactly one word, and nothing else.
